# CAN-FD 링잉과 SIC: 물리 계층과 수신 타이밍의 구분

공개용 개정 기술 노트 · 차량용네트워크 개인 분석 과제 기반 · [English](can-fd-ringing-sic.en.md) · [PDF](can-fd-ringing-sic.pdf)

개인 제출 보고서의 질문은 링잉의 원인과 억제 방법, SIC 트랜시버의 역할이었습니다. 이번 공개본은 학번·연락처와 수업 문항을 제외하고 분석을 다시 작성했습니다. 원문의 일반화와 기술적으로 부정확한 설명도 아래와 같이 정정했습니다. 실측·회로 시뮬레이션 결과는 포함하지 않습니다.

## 분석의 출발점

CAN-FD 수신 타이밍을 볼 때 프레임의 도착 간격만으로 물리 계층을 진단할 수는 없습니다. 임피던스 불연속에서 발생한 반사가 수신 임계값과 샘플 시점에 영향을 줄 수 있지만, 이를 특정 지터의 원인으로 연결하려면 버스 파형과 오류·재전송 기록이 함께 필요합니다. 내 CAN-FD 연구에서 확인한 배경 트래픽 생성 간격의 영향과 링잉 가설은 서로 다른 근거를 요구합니다.

```mermaid
flowchart LR
    W["분기·스텁·종단 조건"] --> R["반사·정착 파형"]
    R --> S["수신 임계값 / 샘플 시점"]
    S --> E["오류 판정 가능성"]
    E --> T["오류 처리·재전송 가능성"]
    T --> L["프레임 도착 타이밍 영향"]
```

이 그림은 분석 경로를 직접 그린 개념도이며 실험으로 입증한 인과 사슬이 아닙니다. TI의 SIC 백서는 복잡한 토폴로지에서 링잉과 비트 시간이 충돌하는 조건, 능동 억제 동작을 설명합니다. [TI SLLA581A](https://www.ti.com/lit/wp/slla581a/slla581a.pdf)

## 세 계층을 나눠 읽기

| 계층 | 확인할 항목 | 이 노트에서 주장할 수 있는 범위 |
|---|---|---|
| 배선·아날로그 | 종단, 스텁, 프로브 위치, D→R 전이의 정착 | 원인 후보와 관측 방법 정리 |
| 컨트롤러 | bit timing, 샘플 포인트, 송신 노드의 TDC/SSP | 설정 의도 설명; 실제 설정·효과 검증은 별도 |
| 트래픽·응용 | 오류 프레임, 재전송, 중재, 송신 스케줄과 수신 시각 | 지터만으로 물리 원인을 확정하지 않음 |

SIC는 단순히 RX 앞에 디지털 필터를 붙이는 방식으로 설명하기 어렵습니다. TI가 설명하는 능동 억제는 dominant(D)에서 recessive(R)로 바뀌는 구간의 버스 구동·임피던스를 제어해 링잉을 줄입니다. TDC/SSP는 송신 노드의 루프 지연을 보상하는 관측 시점과 관련되며, 반사 파형 자체를 제거하지 않습니다. [TI](https://www.ti.com/lit/wp/slla581a/slla581a.pdf), [CiA 601 안내](https://www.can-cia.org/can-knowledge/cia-601-series-can-fd-guidelines-and-recommendations)

## 원문에서 정정한 항목

| 원문의 주장 | 공개본의 정정 |
|---|---|
| SIC를 RX 필터·블랭킹으로만 설명 | 버스 전이의 능동 억제와 컨트롤러 샘플링을 구분 |
| 특정 스텁 길이·속도를 보편 규칙으로 제시 | 해당 장치·배선·토폴로지의 조건 없이 길이·속도 한계를 일반화하지 않음 |
| 제어 신호를 payload 앞에 놓으면 오류 영향을 줄임 | 프레임 수신·검증 이전의 신호 배치만으로 제어 전달 지연 감소를 보장할 수 없음 |
| 긴 패킹 프레임이면 링잉 오류·제어 불안정이 입증됨 | 오류율·재전송·제어 응답의 별도 관측이 필요 |
| SIC의 표준 연도를 단정 | TI TCAN1473A-Q1은 ISO 11898-2:2024와 SIC 적합성을 명시; 해당 장치의 공식 문서 기준으로 기재 |

SIC 동작과 허용 타이밍 조건은 장치 문서에서 함께 확인해야 합니다. 이 노트는 해당 트랜시버를 직접 사용·측정했다는 의미가 아닙니다. [TI TCAN1473A-Q1 공식 문서](https://www.ti.com/product/TCAN1473A-Q1)

## 다음 실험에서 필요한 근거

토폴로지와 트랜시버를 고정하고 차동 파형, 컨트롤러 오류 카운터·오류 프레임, 송수신 타임스탬프를 같은 조건에서 수집해야 합니다. 스텁·종단 또는 SIC 유무를 한 번에 하나씩 바꿔 정착 시간과 오류율을 비교하는 시험은 후속 계획입니다. 이 노트의 표·도식은 새로 작성했으며, 교안·제조사 그림을 복제하지 않았습니다.
