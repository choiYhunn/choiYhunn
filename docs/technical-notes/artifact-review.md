## 이번 검색과 복원 범위

Documents, Downloads, Codex·Claude 작업 폴더, 프로젝트 백업의 파일명과 Python/Arduino/C 코드 내용을 검색했습니다. Windows 사용자 홈의 파일도 추가 확인했습니다. 교육 자료와 Downloads의 ZIP **60개**에서 파일 목록 및 작은 Python/Arduino 소스 **84개**를 검사했으며 주차 애플리케이션의 추가 원본은 발견하지 못했습니다. 대형 백업 전체, 모든 압축 형식과 현재 워크숍 HPC 디스크를 전수 검사했다는 의미는 아닙니다.

이전 Zonal 조사는 배포 ZCU/ECU 폴더와 비교한 범위에 머물러, 다른 위치의 HPC 프로그램과 과거 대화의 실행 자료를 놓쳤습니다. 이번에는 코드의 생성·복사·수정 계보를 복원해 파일명 검색의 한계를 보완했습니다. 원본과 복원본 해시·정확한 로컬 경로·원문 로그는 공개 저장소 밖에 보존했습니다.

## 공개 경계

새 기술 노트는 개인 분석을 바탕으로 다시 작성했습니다. 제3자 그림·교안·과제 정답·상용 라이브러리·수료증 원본·학번·학교 이메일·장비 주소와 사내 자료를 업로드하지 않았습니다. 참고문헌 링크는 해설의 근거이며 원문 재배포가 아닙니다. 코드의 AI 보조 개발과 새 재구성 여부는 Zonal 프로젝트 출처 문서에 모았습니다.
